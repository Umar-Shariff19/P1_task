# Component inventory

| Component | Main locations | Notes |
|---|---|---|
| CLI | `src/iot_ids/cli.py`, `src/iot_ids/__main__.py` | Training, validation, prediction, capture/runtime commands; command paths and side effects vary. |
| Canonical flow/data | `src/iot_ids/data/`, `src/iot_ids/data/adapters/`, `scripts/01_*`, `scripts/03_*` | Data adapters and materialization. Inspect paths before running. |
| Feature construction/schema | `src/iot_ids/features/`, `configs/features/` | Instant, temporal, behavioral builders and profile/schema definitions. |
| Model training/evaluation | `src/iot_ids/training/`, `src/iot_ids/models/`, `scripts/run_golden_pipeline.py` | Golden runner reads all split roles and writes checkpoints/reports. |
| Inference/artifact loading | `src/iot_ids/inference/`, `src/iot_ids/runtime/`, `src/iot_ids/registry/`, `models/final/deployable_artifact/` | Includes deployable artifact metadata and runtime schema. |
| Synthetic runtime smoke path | `src/iot_ids/runtime/synthetic_smoke.py`, `tests/unit/test_runtime_synthetic_workflow.py`, `results/implementation/synthetic_workflow.md` | `python -m iot_ids.runtime.synthetic_smoke` exercises the shared `InferenceEngine.predict()` path using the explicit in-memory `SYNTHETIC_ONLY` constructor branch. RF is fitted on generated rows; MLP is fresh/untrained. No model files or research paths are read. Not a benchmark or real-data authorization. |
| Experiment result status and summaries | `src/iot_ids/experiments/evaluator.py`, `src/iot_ids/experiments/runner.py`, `scripts/04_benchmark_models.py`, `scripts/04_run_benchmarks.py`, `scripts/04_analyze_ablations.py`, `tests/unit/experiments/test_experiments.py`, `results/implementation/experiment_result_status.md` | Stage 4 per-experiment work delegates to the shared runner. The publisher validates an optional canonical manifest and writes `stage4_evidence_status.json`; schema validity is recorded separately from authorization, filesystem identity, integrity, provenance, and scientific validity, all of which remain unestablished/unverified. Both Stage 4 benchmark entrypoints plus direct audit/split loaders now stop before data/output access because real authorization is unavailable. The legacy ablation summarizer labels every row `UNVERIFIED` and preserves empty groups. Rollback publication remains non-atomic for concurrent readers or process/host failure. Other dataset/checkpoint entrypoints remain unguarded and must not be run. |
| Adversarial methods | `src/iot_ids/adversarial/`, `scripts/10_*`, `scripts/13_*`, `scripts/15_*` | Attack and adversarial training/evaluation code; evidence status is limited. |
| Privacy | `src/iot_ids/privacy/`, `scripts/run_privacy_experiments.py` | Experimental; not a validated DP guarantee. |
| Risk calibration | `src/iot_ids/risk/`, `scripts/06_calibrate_risk.py`, `scripts/07_evaluate.py` | Original autoencoder/risk path; distinct from candidate BCL. |
| Explainability | `src/iot_ids/xai/`, `scripts/09_generate_xai_evidence.py`, `scripts/12_run_shap_experiments.py` | Output provenance remains incomplete. |
| Statistical/evidence utilities | `src/iot_ids/statistics/`, `scripts/16_*`–`scripts/24_*`, `reports/` | Preserve historical outputs; generation may read data or overwrite files. |
| Tests | `tests/unit/`, `tests/integration/` | Inspect each target's fixtures, environment, and artifacts before execution. |
| Experiment configuration | `configs/`, `pyproject.toml` | Includes feature, label, split, and compatibility definitions. |
| Dataset path authorization (partial primitive) | `src/iot_ids/data/path_policy.py`, `tests/unit/data/test_path_policy.py`, `results/implementation/dataset_path_safety_policy.md` | Pure pre-discovery lexical gate requires explicit policy, exact root spelling, deny-overlap checks, and typed identity evidence. The evidence object is not trusted OS identity or handle-bound. Audit, discovery, and stream entrypoints remain directly callable. No approved real roots or Windows verifier exist; not real-data enforcement. |
| Prospective experiment provenance | `results/provenance/experiment_manifest.schema.json`, `results/provenance/historical_provenance_matrix.md`, `results/implementation/controlled_experiment_plan.md` | Schema describes future records only; it does not prove approval, execution, or historical linkage. Historical metrics remain `HISTORICAL_REPORTED`; see the per-result matrix. |
| Manifest validation utility | `src/iot_ids/provenance/manifest_validation.py`, `tests/unit/test_manifest_validation.py` | Validates JSON text or an in-memory value against the canonical Draft 2020-12 schema; rejects missing/invalid schema, unsupported dialect/references, and unavailable validator. Failures avoid echoing input values. Structural validity does not authenticate authorization or evidence. Not connected to runners. |
| Artifact digest utility | `src/iot_ids/provenance/artifact_integrity.py`, `tests/unit/test_artifact_integrity.py` | SHA-256 declaration validation is pure; optional byte verification opens one caller-named relative file under an explicit absolute caller-selected base and rejects lexical escape and symlink/reparse components. It does not discover files, authorize the base, prevent concurrent mutation, or establish science/provenance. Synthetic tests only; not connected to runners. |
| Prospective experiment preflight | `src/iot_ids/provenance/preflight.py`, `tests/unit/test_preflight.py` | Coordinates canonical schema validation, an injected authorization policy decision, and optional explicit artifact digest checks. `execute_after_preflight()` invokes a callback only after synthetic-only readiness and propagates callback failures. It categorically refuses real-data authorization. No trusted provider exists; the only permitting policy is test-local. It is not connected to data-reading runners or adapters. |
| Experiment runner integration points | Dispatcher: `scripts/run_master.py`; direct training: `scripts/train_rf.py`, `scripts/train_mlp.py`, `scripts/train_ae.py`, `scripts/05_train_models.py`, `scripts/13_run_adversarial_training.py`, `scripts/run_golden_pipeline.py`, `scripts/run_privacy_experiments.py`; direct evaluation: `scripts/evaluate_v2.py`, `scripts/evaluate_cross_domain.py`, `scripts/07_evaluate.py`, `scripts/10_run_adversarial_evaluation.py`, `scripts/14_run_ensemble_experiments.py`; benchmarks: `scripts/04_run_benchmarks.py`, `scripts/04_benchmark_models.py`, `scripts/benchmark_runtime_xai_privacy.py`; adapters: `src/iot_ids/data/adapters/base.py` and dataset adapter modules | Static source review only. Dispatcher subprocesses have no shared preflight and children are independently invokable. Direct scripts read split files and/or load checkpoints before any preflight. `DatasetAdapter.audit()`, subclass discovery, and streaming methods remain directly callable; CICIoT2023 discovery uses recursive globbing. Manifest validation, authorization, and integrity are not enforced in these paths. Do not run these entrypoints under unresolved prerequisites. |
| Phase S bounded entrypoint audit | `results/implementation/phase_s_entrypoint_audit.md` | Source-only scan of 150 Python files under `scripts/` and `src/` plus targeted caller analysis. It records direct entrypoints, dispatch bypasses, I/O classes, and known uncertainty; not a claim of exhaustive dynamic call-graph coverage. |
| Future Windows authorization design | `results/implementation/windows_filesystem_authorization_spec.md`, `results/implementation/dataset_access_policy.schema.json`, `results/implementation/dataset_access_policy.example.json`, `tests/unit/test_dataset_access_policy_schema.py` | Specification and schema are design artifacts only. Schema-validity does not authenticate owner approval or authorize files. No production provider or runtime change exists. Synthetic example has only placeholder/null roots and no approvals. |
| Windows access enforcement primitives (fail-closed) | `src/iot_ids/provenance/windows_access.py`, `src/iot_ids/provenance/windows_handle.py`, `src/iot_ids/provenance/windows_root.py`, `tests/unit/test_windows_access.py`, `tests/unit/test_windows_root.py` | Policy provider remains an unconditional real-access refusal. The child helper opens one child relative to a supplied HANDLE. The root helper queries metadata from a caller-owned handle as `OBSERVED_UNVERIFIED`; `WindowsRootHandleAcquisitionProvider` returns `UNAVAILABLE` without touching its inputs because the documented user-mode no-reparse contract is insufficient to establish safe all-component acquisition. It does not acquire a path-based root, authenticate provenance/approval, or authorize access. Neither helper is used by production runners/adapters. See Phases T/U/V and the API-contract review in the Windows authorization specification. |

Official artifacts were not regenerated during repository cleanup. Manuscript build assets are archived outside the repository; useful project context and research evidence remain in place.
